WHAT IS THIS?
─────────────
A Discord bot that automatically:
- Syncs timesheet entries from iPhone to cloud
- Extracts invoices from Outlook
- Generates monthly Excel reports
- Runs on Railway cloud (24/7)

QUICKSTART (30 MIN)
───────────────────

1. Setup environment:
   $ cd ~/timesheet-bot
   $ ./setup.sh
   $ source venv/bin/activate

2. Get Microsoft token (one-time):
   $ python auth/ms_auth.py
   [Follow instructions, copy token to .env]

3. Fill credentials in .env:
   - AZURE_CLIENT_ID
   - MICROSOFT_REFRESH_TOKEN
   - DROPBOX_APP_KEY, etc.
   - DISCORD_BOT_TOKEN, etc.
   [See SETUP.md for detailed instructions]

4. Start bot locally:
   $ python main.py
   [Bot should appear online on Discord]

5. Test on Discord:
   /status
   /rapport
   /sync

DEPLOYMENT
──────────

When ready to go live:

   $ npm install -g @railway/cli
   $ railway init
   $ railway deploy

Bot will run 24/7 on Railway. Monthly reports auto-generate on 1st of month.
